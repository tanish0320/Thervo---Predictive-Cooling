BUG #1: CRITICAL - psutil.cpu_percent() Caching Issue

  Location: src/inference.py:129-161

  Impact: Eliminated artificial CPU deflation

  Location: src/inference.py:196-199, 239-240

================================================================================
KEY INSIGHT
================================================================================

The primary issue was NOT power weighting but psutil API limitation:
- psutil.cpu_percent(interval=None) returns CACHED values from 1 second ago
- When called every second, alternates between fresh and cached (0%)
- Fix: Use psutil.cpu_percent(interval=0.1) for fresh measurement

This was the root cause of the zero readings that made troubleshooting difficult.
