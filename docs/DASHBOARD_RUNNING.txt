WHAT'S HAPPENING RIGHT NOW
================================================================================

The system is collecting REAL-TIME data from your PC:

1. CPU Utilization (%)
   - Real-time measurement from psutil
   - Updated every 1 second
   - Displayed on dashboard

2. GPU Utilization (%)
   - If NVIDIA GPU available: from nvidia-smi
   - Cached every 2 seconds (optimized)
   - Shows power draw (Watts) and temperature

3. Memory Usage (%)
   - Real-time from OS
   - Updated every 1 second

4. Disk & Network I/O
   - I/O rates in bytes/second
   - Cached every 10 seconds (optimized)

5. Temperatures
   - CPU temperature (if available)
   - GPU temperature (if available)
   - Fallback estimation if sensors unavailable

6. AI Risk Prediction
   - XGBoost model predicts thermal risk (0.0 - 1.0)
   - GNN embedding adds multi-machine awareness
   - Risk score used to control fan speed

7. Thermal Mode Control
   - QUIET: 1000 RPM (risk < 0.35)
   - BALANCE: 1800 RPM (0.35 < risk < 0.65)
   - PERFORMANCE: 3500 RPM (0.65 < risk < 0.85)
   - EMERGENCY: 5500 RPM (risk > 0.85)
